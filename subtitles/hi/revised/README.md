# Hindi — première correction textuelle

[prema-kavali.hi.revised.srt](prema-kavali.hi.revised.srt) contient une première passe de correction de l'orthographe, de la syntaxe locale, de la typographie et de certaines erreurs de transcription reconnaissables dans le contexte.

**Brouillon non validé à l'écoute.** Les 932 blocs, leur numérotation et leurs horodatages sont conservés. Les 17 durées nulles ou négatives restent à corriger avec l'audio; aucun dialogue manquant n'a été reconstruit à partir d'un autre scénario ou d'une traduction.

Voir le [bilan](../../../reports/revision-hi.md), le [journal avant/après](../../../reports/corrections-hi-v1.csv), les [607 blocs à vérifier](../../../reports/a-verifier-audio-hi.csv) et la [validation technique](../../../reports/validation-hi-revised.json).

Les corrections de transcription fondées sur le contexte sont des propositions, pas une certification des paroles prononcées. Ne pas utiliser cette passe comme source définitive d'une traduction française sans révision audiovisuelle. Le SRT original est intact dans le dossier voisin `original/`.
